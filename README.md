# 🧠 AI Software Explore & Learning Hub

A modern, responsive, and interactive web educational platform designed to help students and beginners explore Artificial Intelligence software, learn AI concepts step-by-step, master prompt engineering, and build real-world AI project blueprints.

## 🌟 Key Features

- **🎨 Modern Cyberpunk / Neumorphic Aesthetic**: Ambient gradient glows, glassmorphism (`backdrop-filter: blur`), dark/light theme switching with instant state persistence.
- **🔍 Interactive AI Software Directory**: Searchable and filterable database of 24+ top AI tools across 9 categories (Generative AI, Coding, LLMs, Image/Video Generation, Data Science, etc.).
- **📊 AI Tools Comparison Matrix**: Compare tools by purpose, skill level, pricing model (Free/Freemium/Paid), user ratings, and best use cases.
- **🎓 9 Structured Skill Learning Paths**: Step-by-step tracks covering AI Basics, Prompt Engineering, Python, Machine Learning, GenAI, and Computer Vision with interactive lesson progress bars.
- **🛠️ 7 Hands-on Beginner AI Projects**: Complete execution blueprints for AI Chatbots, DALL-E Image Generators, Student Study Assistants (RAG), ATS Resume Analyzers, and Voice Assistants.
- **📚 Curated Knowledge Base & Resources**: Links to official documentation (OpenAI, PyTorch, Hugging Face), YouTube channels, prompt cheat sheets, and interactive self-test quiz.
- **⭐ Bookmark / Favorites System**: One-click favorite tool saving stored locally in the browser.
- **📱 Fully Responsive Layout**: Tailored mobile drawer menu, tablet grid scaling, and desktop viewports.

## 🚀 How to Run the Project Locally

No complicated build steps or dependencies required!

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/AI-Software-Explore-Learning.git
   ```
2. **Navigate into the Project Folder**:
   ```bash
   cd AI-Software-Explore-Learning
   ```
3. **Launch in Browser**:
   - Double-click `index.html` to open it in your default web browser (Chrome, Firefox, Edge, Safari).
   - Alternatively, open with VS Code's **Live Server** extension for real-time live reload.

## 🌐 Deploying to GitHub Pages

Publish this platform online for free using **GitHub Pages**:

1. Push your code to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial release of AI Software Explore & Learning Hub"
   git branch -M main
   git remote add origin https://github.com/your-username/AI-Software-Explore-Learning.git
   git push -u origin main
   ```
2. On GitHub, navigate to your repository **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
4. Set Branch to `main` and Folder to `/ (root)`.
5. Click **Save**. Your live website link will be ready in a couple of minutes!
